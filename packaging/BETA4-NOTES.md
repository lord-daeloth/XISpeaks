## XISpeaks beta 4

Windows x64 / Ashita. Download the app ZIP and both voice ZIPs and extract all three into the same addons directory. Run XISpeaks/START-XISpeaks.cmd, then /addon load XISpeaks and /xis voices. Models are bundled for offline playback.

- Refreshed curated catalog: 589 voices; unreferenced voice files excluded.
- Blank-slate NPC voices: no shipped manual assignments, tuning overrides or approvals. Race/type information remains.
- No random pitch or speed fluctuations. Edit each NPC type's pitch/speed directly in the addon.
- Room and NPC reverb: Dry, Small Room, Stone Hall, Cave and Ethereal, with global strength and off switch.
- Review popup: Play Again replays the actual line; Reject tries another eligible voice; Approve locks it in. Edit remains available.
- One addon and companion name: XISpeaks. The XISpeaksPocket test variant is retired.

Upgrade into a fresh folder after backing up the old installation. For a clean slate, do not copy the old runtime database. Update auto-start entries and use /xis commands. Existing users' personal databases are never silently wiped by an update.

Voice-specific terms and credits are in VOICE-LICENSES.md. Noncommercial profiles remain subject to their separate terms. Source and third-party notices are included. This beta is marked Latest for the default download.
